# House Dimensions website

A responsive, static website for House Dimensions. Built with plain HTML, CSS and JavaScript so it can be hosted on GitHub Pages.

## Before publishing

1. Replace `YOUR-EMAIL@example.com` in `script.js` with the email address that should receive enquiries.
2. Replace the temporary text wordmark in `index.html` with your approved logo when ready. The `.brand` / `.brand-mark` styles are in `styles.css`.
3. Review the service descriptions and confirm that every service listed reflects what House Dimensions offers.
4. Replace the sample photography URLs in `styles.css` with approved company/project photography when available. Current imagery is loaded from Unsplash and requires an internet connection.
5. Add your phone number, preferred contact details, and any specific towns you serve once confirmed.

## Publish with GitHub Pages

1. Create or open the GitHub repository you want to use (for a user site, the repository is usually named `YOUR-USERNAME.github.io`).
2. Upload the contents of this folder to the repository root: `index.html`, `styles.css`, `script.js`, and this README.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and use the URL shown in the Pages settings.

If using a project repository rather than `YOUR-USERNAME.github.io`, GitHub Pages will publish under `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Contact form note

The form uses a `mailto:` link. It opens the visitor's configured email application and pre-fills the enquiry; it does not silently submit or store information. For a true on-page form submission, connect a form service or backend later.

## Image and brand note

The current visual identity is a temporary typographic wordmark. The site does not imply any specific Control4 certification wording beyond the dealer relationship supplied for this draft. Confirm approved partner language and logo-use requirements before publishing.
