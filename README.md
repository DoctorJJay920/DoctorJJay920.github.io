# House Dimensions — Brand-Aligned Website

A responsive one-page website using the supplied House Dimensions logo and its existing brand palette:
- Charcoal / near-black
- White and light grey
- Brand red accent

## Files
- `index.html` — page content and sections
- `styles.css` — visual design, responsive layouts and mobile navigation styling
- `script.js` — mobile menu, current year and contact form mailto behavior
- `assets/house-dimensions-logo.png` — supplied logo image

## Before publishing
1. Open `script.js` and replace `YOUR-EMAIL@example.com` with the email address you want enquiries sent to.
2. Confirm the wording of all services and Control4 dealer status.
3. Replace the sample stock photos with approved House Dimensions showroom, installation and project photos.
4. Consider adding a real form service if you want visitors to submit without opening their email application.

## Publish with GitHub Pages
1. Upload the contents of this folder (not the ZIP itself) to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

The website uses Google Fonts and sample remote images from Unsplash, so those assets require an internet connection. The contact form is client-side only and does not store information.
