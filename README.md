# House Dimensions — refreshed website

A responsive, one-page website using the new charcoal (`#1A1C1E`), brushed brass (`#C5A059`) and bone-white (`#F4F4F0`) identity. The supplied emblem artwork is included in `assets/house-dimensions-emblem.png` and used in the header and footer.

## Before publishing
- Replace `YOUR-EMAIL@example.com` in `script.js` with the business email.
- Confirm the precise public wording for the Control4 dealer relationship.
- Replace sample Unsplash images with approved House Dimensions and project photography.
- Confirm the service descriptions and business contact details.

## Preview
Open `index.html` in a browser. Google Fonts and sample photography are externally hosted, so the preview needs internet access.

## GitHub Pages
Upload the contents of this folder to the repository root. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Contact form
The form currently opens the visitor's email application using `mailto:`. It does not store or submit enquiries to a server. A hosted form service/backend can be connected later.

## Logo note
The supplied logo image is an embossed presentation mockup. A flat SVG/vector master would reproduce more cleanly at small sizes and across print, signage and web use.
